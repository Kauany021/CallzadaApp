# Callzada

Aplicativo desktop de mensagens, chamadas de voz e transmissão de tela P2P,
com criptografia de ponta a ponta.

Callzada is a peer-to-peer desktop app for messaging, voice calls and screen
sharing, with end-to-end encryption.

## Recursos

- Conversas privadas com texto, arquivos, mensagens de voz e GIFs
- Chamadas de voz e transmissão de tela
- Grupos com canais de texto e de voz
- Login com conta Google

## Como funciona

As mensagens, os arquivos e as chamadas vão direto entre os aparelhos, sem
servidor de mensagens. Quando a rede não permite conexão direta, os dados
passam por relays que só veem bytes cifrados, além de endereços IP e chaves
públicas.
